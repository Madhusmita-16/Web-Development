# 🍷 Maison Élan — Luxury Fine Dining & Online Ordering Web Platform

> A premium, modern, fully responsive **fine-dining restaurant web application** built with HTML5, CSS3, Vanilla JavaScript, Bootstrap 5, and GSAP + ScrollTrigger for smooth motion, glassmorphism UI, and seamless food ordering.

## 🌟 Key Features

* **3-Card Initial Menu View**: Signature menu presents 3 featured Best Sellers initially, with a smooth **"Show More Dishes"** expansion button.
* **155 Gourmet Delicacies**:
  * **30 Authentic Indian Starters**: Tandoori Paneer Tikka, Chicken Galouti Kebab, Amritsari Fish Tikka, Dahi Ke Kebab, Kakori Kebab, etc.
  * **50 Authentic Indian Main Courses**: Paneer Velvet Butter Masala, Murgh Makhani, 24-Hr Slow Dal Élan, Hyderabadi Dum Biryani, Kashmiri Rogan Josh, Shorshe Ilish, etc.
  * **25 Continental Main Courses**: Black Truffle Pasta, Pan-Seared Salmon, Ribeye Steak, Lobster Thermidor, etc.
  * **25 Desserts**: Valrhona Dark Chocolate Fondant, Classic Tiramisu, Crème Brûlée, Gulab Jamun Cheesecake, etc.
  * **25 Drinks & Beverages**: Passionfruit Gold Mocktail, Royal Saffron Lassi, Cold Brew Espresso Tonic, etc.
* **Interactive Order Basket**:
  * Real-time item additions with quantity increment/decrement (`[-] 1 [+]`) and price calculations.
  * Automatic 5% GST tax calculation and grand total display.
  * Table selection dropdown (Dine-in Table 1, Table 4 VIP Booth, Terrace View, Takeaway, Delivery).
  * **"Place Order Now"** celebratory modal with kitchen status progress bar.
* **30 High-Resolution Photo Gallery**: Includes full-screen interactive lightbox modal with keyboard navigation (`Left`/`Right`/`Esc`).
* **Table Reservation System**: Form validation with date picker, time slot, guest count, and instant confirmation state.
* **Modern SaaS Aesthetic**: Dark luxury theme (`#0a0805`), warm gold accents (`#c9a84c`), glassmorphism cards, and GSAP ScrollTrigger reveals.

---

## 🛠️ Technology Stack

* **Frontend**: HTML5, CSS3 (Custom Variables, Flexbox, CSS Grid)
* **Framework**: Bootstrap 5.3
* **Animations**: GSAP (GreenSock Animation Platform) + ScrollTrigger
* **Icons**: Font Awesome 6
* **Typography**: Google Fonts (*Cormorant Garamond*, *Playfair Display*, *Inter*)

## 🚀 Quick Start & Local Run

```bash
# Clone the repository
git clone https://github.com/Madhusmita-16/Web-Development.git
cd Web-Development/restaurant-website

# Serve locally
npx serve . -p 3003
```
Open your browser and visit: `http://localhost:3003`
