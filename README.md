# 🌐 Web Development Showcase Repository

Welcome to the **Web Development Collection** by [Madhusmita-16](https://github.com/Madhusmita-16/Web-Development). This repository showcases four premium, modern, fully responsive web applications built with HTML5, CSS3, Vanilla JavaScript, Bootstrap 5, and GSAP.

---

## 📁 Web Applications Overview

| Project | Description | Live Local Port | Navigation Clip |
| :--- | :--- | :---: | :---: |
| **[Maison Élan Restaurant](restaurant-website/)** | Luxury fine-dining platform with 155 delicacies (30 Indian Starters, 50 Indian Mains), 30 gallery photos, live search, and interactive order basket. | `http://localhost:3003` | [View Clip](restaurant-website/demo-navigation.webp) |
| **[Nexora Social Network](nexora/)** | 2026 futuristic SaaS social platform with glassmorphism UI, story reels, dark mode, and authentication forms. | `http://localhost:3004` | [View Clip](nexora/demo-navigation.webp) |
| **[ConnectHub Facebook Clone](facebook-clone/)** | Feature-complete Facebook clone with feed reactions, comment threads, sidebar widgets, and dark mode. | `http://localhost:3005` | [View Clip](facebook-clone/demo-navigation.webp) |
| **[ApexFit Fitness Website](fitness-website/)** | Luxury gym website with WHO BMI calculator, training program catalog, and membership tier plans. | `http://localhost:3006` | [View Clip](fitness-website/demo-navigation.webp) |
